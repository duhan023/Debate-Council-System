# Debate Council scoring rubric

Score every argument that survives to closings on three dimensions. Weight is the product, not the sum — a fabricated fact or a broken inference zeroes the argument regardless of the other scores.

## 1. Evidence tier (what the argument rests on)

| Tier | Score | Description |
|---|---|---|
| T1 | 5 | Verified primary data: official figures, filings, measured numbers, direct documentation confirmed in this session |
| T2 | 4 | Peer-reviewed research — meta-analyses and systematic reviews at the top of this tier, single studies at the bottom |
| T3 | 3 | Recognised professional standard or expert body consensus (PMI, ISO, NIST, clinical guidelines, regulator guidance) |
| T4 | 2 | Credible practitioner sources: named experts, reputable trade press, documented case studies |
| T5 | 1 | Anecdote, analogy, intuition, or unsourced general knowledge |
| T0 | 0 | Unverifiable or fabricated. Argument is struck. |

A claim that only needs logic, not data (e.g. "the option expires before the decision point, so it cannot be exercised") is scored on validity alone and takes T3 for evidence by default.

## 2. Logical validity (does the conclusion follow)

| Score | Description |
|---|---|
| 3 | Valid: premises true → conclusion follows. No hidden assumptions. |
| 2 | Mostly valid: one stated assumption that is plausible but unproven |
| 1 | Weak: relies on an unstated or contested assumption, or generalises from too little |
| 0 | Fallacious (false dilemma, post hoc, appeal to authority without relevance, motte-and-bailey, etc.). Argument is struck. |

## 3. Rebuttal survival (what happened under cross-examination)

| Score | Description |
|---|---|
| 3 | Rebutted and the response fully answered the rebuttal |
| 2 | Unrebutted — the other bench did not engage it |
| 1 | Rebutted; partially answered, some force remains |
| 0 | Rebutted and conceded or left unanswered when an answer was needed. Argument is struck. |

Note the ordering: an argument that was attacked and defended outscores one nobody bothered to attack. Silence from the other bench is not the same as strength.

## Computing the ruling

1. Weight = evidence × validity × survival. Maximum 45.
2. Rank all surviving arguments across both benches.
3. The verdict goes to the bench holding the highest-weighted argument, unless the other bench holds two or more arguments each within 20% of it — then the judge must reason explicitly about whether they compound or merely repeat.
4. Confidence:
   - High: top argument ≥ 30 and no opposing argument ≥ 20
   - Medium: top argument ≥ 20, or the top two are on the same bench
   - Low: everything else, or the verdict rests on a single T4/T5 argument
5. The Dissent is the highest-weighted surviving argument on the losing bench. It must be stated even when its weight is low.
6. Conditional verdicts arise when the top argument's evidence score depends on a fact the user has not supplied. Insufficient evidence arises when no argument on either bench exceeds weight 12.

## What the rubric does not do

It does not replace judgment on what matters to the user. Two arguments can both score 36 and one can still be irrelevant to the motion as framed. Score first, then ask whether the highest-weighted argument actually answers the question. If it does not, say so in the Decisive factor line and explain which argument did.
